# 高频基础题精讲

这组题来自真实面试统计，特点是看起来基础，但面试官会沿着一个问题连续追问原理、边界和项目实践。

## 学习方法

每篇都按同一条路径阅读：

1. **先建立直觉**：先不用术语，知道这项技术要解决什么问题。
2. **再看机制链**：把输入、调度、转换、输出串起来。
3. **再看最小例子**：用代码验证理解，不背大段源码。
4. **最后练面试表达**：先讲 30 秒，再展开 2 分钟，最后回答追问。

## 推荐顺序

```text
事件循环
  -> 浏览器渲染
  -> Vue 响应式与双向绑定
  -> KeepAlive
  -> HTTP/1.1 到 HTTP/3
  -> Webpack 打包流程
  -> Webpack 与 Vite
  -> ES6 特性穿插复习
```

这不是技术栈的唯一顺序，而是面试追问最常见的路径：JavaScript 调度影响 Vue 更新，浏览器渲染承接页面性能，网络和构建工具再解释工程结果。

## 面试回答模板

```text
先说结论：它解决什么问题，核心机制是什么。
再说过程：关键步骤按时间或数据流展开。
再说边界：什么时候不适用，常见误区是什么。
最后落项目：我会如何使用、排查和验证。
```
