# 2026 Vue 面试更新手册

> 面向以 Vue 2 业务项目为主、希望系统补足 Vue 3、TypeScript、Pinia 与 Vite 的资深前端工程师。

这套手册独立于旧笔记。旧笔记是取材来源，不是阅读前置条件；本手册会保留仍然高频且正确的内容，并用当前的框架和浏览器实践重新表达。

## 怎么读

- **P0**：高频核心题。需要能在 30 秒内给出结论，并经得起追问。
- **P1**：常见延伸。用于把答案讲完整、体现项目经验。
- **P2**：场景补充。适合查漏和应对具体业务追问。

每个核心问题尽量按以下顺序组织：`30 秒回答`、`展开说明`、`最小代码示例`、`项目表达`、`可能追问`。Vue 3、TypeScript、Pinia 与 Vite 会从 Vue 2 已有经验切入，代码用于帮助理解，不要求先掌握新语法。

## 使用原则

先把 P0 讲顺，再补 P1 和 P2。面试回答不需要背诵全文，但应做到：结论准确、边界清楚、能落到真实项目，且不虚构没有做过的结果或数据。
